Quick Pane 改造为本 App 的快捷搜索入口。

- 阶段 1 搜索已注册模块，支持模块名、缩写、模块 ID 和别名的模糊搜索。
- 支持鼠标点击、上下箭头、Tab 和 Enter 选择搜索结果，并唤起主窗口切换到目标模块。
- 阶段 2 支持模块内搜索扩展点；用户选中支持搜索的模块后继续输入，会交给模块自己的 `quickSearch` 处理。
- GTD 接入模块内搜索，可按文档标题、Markdown 标题、文件名和路径搜索并打开对应文档。
- 阶段 2 输入为空时继续按 Backspace/Delete，会退回阶段 1 模块搜索。
- 增加 Strange Reminder / 奇怪提醒 空白占位模块，缩写 RMD，用于验证模块搜索和切换效果。
