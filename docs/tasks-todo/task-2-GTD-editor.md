Heading Folding: Integrated a custom Prosemirror plugin that adds a toggle icon next to every heading. Folding a heading hides all subsequent content until the next heading of the same or higher level.
Code Block Folding: Added a collapse mechanism for code blocks, allowing users to hide long scripts and keep the document clean.
Blockquote Folding: Enabled folding for blockquote sections, which is particularly useful for long citations or nested comments.
Inline Rendering: Leveraged Milkdown Crepe's native WYSIWYG capabilities for real-time rendering of bold, italic, links, and task lists.
